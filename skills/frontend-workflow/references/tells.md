# Tells

A tell is a device that makes a page read as generated. Most began as good ideas; they became tells
by appearing by default, whatever the subject. The fixes below are procedures, not products: any
named "use this instead" font or colour turns into the next tell within months. Revise this list as
the defaults shift.

Adapted from [Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill)@12af471
(MIT, `LICENSE-taste-skill`).

How to read it:

- **Remove**: take it out, unless the brief asks for it or the app's existing look already uses it.
- **Needs a reason**: keep it only if you can say what it does for this content.
- **The direction** means the app's own tokens, or the plan from `landing-page-design` on new visual
  ground.
- The list targets landing and marketing pages. On app screens (dashboards, settings, admin views),
  quiet borders, small labels, repeated panels and monospace for code or IDs are normal. Gradients,
  glows, icons in tinted squares and invented numbers are still tells there.

## Colour and surface

| Tell | Status | Instead |
| --- | --- | --- |
| Violet or indigo gradients on hero, buttons and glows | Remove | Flat colour from the direction |
| Gradient-filled headline text | Remove | Solid ink |
| Glowing or gradient call-to-action button | Remove | A flat button named for its action |
| The same soft grey shadow under every card | Remove | A tone step, or no box |
| Glass panels: backdrop blur, translucent cards | Needs a reason | Opaque surfaces one tone step from the ground |
| Near-black ground with one neon accent and a glow | Remove | A dark palette from the direction, no glow |
| Cream ground with a terracotta or clay accent | Remove | Warmth from a low-chroma stone, a deep ink, a photograph, or a full warm field |

## Type

| Tell | Status | Instead |
| --- | --- | --- |
| The typeface you would use on any page | Needs a reason | Type from the direction |
| One word of a headline in italic, colour or underline | Remove | One face, one colour |
| Eyebrow: a tiny tracked uppercase label above a heading | Remove | Fold it into the heading, or delete it |
| Tiny letter-spaced uppercase captions around the page | Remove | Sentence case at a readable size, next to what it describes |
| Monospace labels as a "technical" voice | Needs a reason | The text face; tabular figures for data |
| High-contrast or oversized italic serif as the shortcut to "premium" | Needs a reason | Type from the direction |
| A display headline running over two lines | Remove | A title of about five words; the rest goes below |
| Many nearly equal font sizes | Remove | About five sizes, far apart |

## Layout and structure

| Tell | Status | Instead |
| --- | --- | --- |
| Three identical feature cards, each with an icon in a rounded square | Remove | A composition built for that content |
| Bento grid of rounded tiles as the feature section | Needs a reason | A composed section |
| Centred headline, subtitle, two buttons, screenshot below | Needs a reason | A hero from the subject |
| Pill badge above the hero headline ("New", "Beta") | Remove | Say it in the supporting sentence |
| Floating rounded pill navigation with blur | Needs a reason | A plain bar |
| Fake dashboard built from grey bars and donut charts | Remove | A real interface fragment, or no image |
| Stock section order: hero, logos, features, testimonial, pricing, CTA | Needs a reason | The order of the argument |
| Every section in the same layout | Remove | A different composition per section |
| Everything centred | Remove | Left-anchored, with one centred moment |
| One medium radius (12–16px) on everything | Needs a reason | Radius chosen once, following hierarchy |
| Broadsheet look: hairline rules everywhere, zero radius, dense columns | Needs a reason | Structure from space and tone |
| Index numbering: 01 / 02 / 03, "Step 02" | Needs a reason: the content is a real sequence | Order by position or scale; `<ol>` for a real list |
| Design-tool chrome as ornament: crosshairs, crop marks, rulers, dashed guides | Remove | Nothing |
| Text or a CSS box where a picture belongs | Remove | A real picture, or a design that needs none |

## Copy and decoration

| Tell | Status | Instead |
| --- | --- | --- |
| Emoji as icons or bullets | Remove | Words, or a real picture |
| Decorative status dot ("Available for work", a pulsing "live") | Remove | Nothing |
| Agency micro-meta: local time, coordinates, version stamps, "©2026 — Scroll", middle-dot strings | Remove | Nothing |
| Performative labels: "Field notes", "Quietly trusted by" | Remove | Plain section names |
| Invented social proof: logos, quotes, star rows, "10,000+ teams" | Remove | Real proof, or none |
| Genre words: unlock, supercharge, seamless, elevate, effortless, cutting-edge, all-in-one | Remove | Say what it does |
| "Not just X, it's Y"; three-part headlines | Remove | One plain claim |
| "Get started" and "Learn more" as labels | Remove | Name the action |
| Lorem ipsum | Remove | Real or realistic content |

## Motion

| Tell | Status | Instead |
| --- | --- | --- |
| The same fade-up on every section; staggered hero entrances | Remove | One orchestrated moment |
| Hover lift on every card | Remove | Hover feedback only where it shows something |
| Bounce easing; infinite loops that mean nothing | Remove | Nothing |
| Reveals that can fail and leave a blank band | Remove | Content visible without the animation |

## Removing is not enough

A page with every tell removed and nothing in their place is a tell too: anyone could guess it from
the category plus this list. The tells were filling a gap where an idea should have been. Fill that
first, from the subject (the direction), then run this list.
